# IDB Database Administration Portfolio

Three interactive portfolio demos built around the responsibilities in the public OFIFC database-administration job description.

**Live demo:** https://ofifc-idb-portfolio.vercel.app

> **Disclosure:** Independent portfolio work. Not affiliated with OFIFC. No real OFIFC, Friendship Centre, client, employee or program-level records are used; all displayed operational data is synthetic.

## 1) IDB Admin Console
`idb-admin-console/`

- Database performance and availability
- User / role administration and access reviews
- SQL-style reporting query workspace
- Controlled exports
- Backup / recovery controls
- Auditability and system development testing
- Improvement recommendations

## 2) Program Data & Reporting
`program-data-reporting/`

- Data completeness and validation
- Duplicate / quality monitoring
- Cross-program analytics
- Statistical summaries analogous to SPSS workflows
- Scheduled reporting and exports
- Shared metric governance across workgroups

## 3) IDB Support & Training
`idb-support-training/`

- Front-end user support and ticket analysis
- SLA / recurring-issue monitoring
- Role-specific training plans and resources
- Contractor liaison and development monitoring
- Release readiness
- Senior-management status briefings
