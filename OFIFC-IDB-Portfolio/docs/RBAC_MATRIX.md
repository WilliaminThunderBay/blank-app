# RBAC Matrix

| Capability | Administrator | Analyst | Support | Viewer |
|---|---:|---:|---:|---:|
| Manage users / roles | Yes | No | No | No |
| Run reporting queries | Yes | Yes | No | No |
| Edit program records | Yes | Yes | No | No |
| Export governed data | Yes | Yes | No | No |
| Resolve support tickets | Yes | No | Yes | No |
| Run release/admin tests | Yes | No | No | No |

The live demo enforces this matrix in the UI and records role changes and actions in the demo audit log.
